# سایت دورهمی‌های خودمونی

نسخه دوم سایت: ظاهر ساده‌تر مطابق بازخورد، عنوان اصلی «سایت دورهمی‌های خودمونی» و پنل مدیریت برای تغییر عنوان دورهمی، مکان، تاریخ/ساعت، توضیحات و عکس. پاسخ مهمان‌ها و آمار نیز فقط در پنل مدیر دیده می‌شوند.

## راه‌اندازی
1. یک پروژه در [Supabase](https://supabase.com/) بسازید.
2. در SQL Editor کل فایل `supabase.sql` را اجرا کنید.
3. در Project Settings → API مقدار Project URL و کلید `anon` یا `publishable` را بردارید و در `config.js` جایگزین مقادیر `YOUR_...` کنید. هرگز `service_role` را منتشر نکنید.
4. در Authentication → Users یک حساب مدیر بسازید. فقط همین حساب (و حساب‌های مجاز دیگری که خودتان ایجاد کنید) وارد پنل می‌شوند.
5. فایل‌ها را در ریشه یک repository در GitHub قرار دهید.
6. Settings → Pages → Deploy from a branch → شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
7. در Supabase → Authentication → URL Configuration آدرس GitHub Pages را به Site URL و Redirect URLs اضافه کنید.
8. سایت را باز کنید و از لینک «ورود مدیر» وارد `admin.html` شوید. در بخش «ویرایش اطلاعات دورهمی» عنوان، مکان، تاریخ و ساعت، توضیحات و عکس را ثبت و ذخیره کنید.

## امکانات
- صفحه اصلی با سربرگ «سایت دورهمی‌های خودمونی»
- فرم حضور / عدم حضور / نامشخص
- مدیر می‌تواند اطلاعات رویداد و تصویر (JPG/PNG/WEBP تا ۵ مگابایت) را تغییر دهد.
- مدیر می‌تواند فهرست مهمان‌ها و آمار را ببیند و CSV بگیرد.
- پاسخ‌های مهمان‌ها در فرم عمومی فقط قابل ثبت است؛ شماره تکراری امکان ثبت مجدد ندارد.

## نکات امنیتی
- Row Level Security برای خصوصی نگه‌داشتن فهرست مهمان‌ها فعال است.
- تنظیمات دورهمی برای همه قابل خواندن است، اما فقط کاربر احراز هویت‌شده می‌تواند تغییر دهد.
- خواندن پاسخ‌ها فقط برای کاربران واردشده مجاز است. در فرم عمومی، مهمان‌ها فقط INSERT دارند.
- این نسخه تأیید پیامکی شماره موبایل ندارد؛ شماره موبایل به‌تنهایی هویت را اثبات نمی‌کند. برای جلوگیری از جعل شماره، در صورت نیاز تأیید OTP و CAPTCHA اضافه کنید.
- کلید `service_role` را هرگز در کد سمت مرورگر یا GitHub قرار ندهید.
